Datos del Aprendiz

Caso de Estudio: "Sistema de Gestión de Inventarios - TechFlow Solutions"

Contexto Operativo

La empresa TechFlow Solutions requiere automatizar el control de sus activos tecnológicos. Tras concluir la fase de diseño, su equipo debe codificar el Módulo de Registro y Consulta de Dispositivos.

Persistencia de Datos
API REST para Móvil
Altos Estándares de Seguridad

Procesos Técnicos y Requerimientos (7 Ítems)

Total: 100% (448 Horas)

Implemente en su entorno de desarrollo una plantilla de estándares de codificación que incluya: reglas de nombrado (CamelCase / snake_case), indentación y documentación interna de clases y métodos.

Trabajo Directo: 40 hrs Trabajo Autónomo: 4 hrs Soporte: AA03_ED02

Desarrolle la lógica de los módulos principales utilizando el Paradigma Orientado a Objetos (POO), asegurando que cada clase (ej. Activo, Categoria, Usuario) responda a los diagramas de diseño previos.

Trabajo Directo: 70 hrs Trabajo Autónomo: 8 hrs Soporte: AA03_ED03

Construya una API RESTful que permita la comunicación de datos entre el Front-end y el servidor, utilizando formato JSON para el intercambio de información y métodos HTTP estandarizados.

Trabajo Directo: 70 hrs Trabajo Autónomo: 8 hrs Soporte: AA03_ED04

Codifique mecanismos de protección para prevenir vulnerabilidades críticas como el SQL Injection y aplique algoritmos de encriptación (SHA256/BCrypt) para el manejo seguro de credenciales de acceso.

Trabajo Directo: 50 hrs Trabajo Autónomo: 6 hrs Soporte: AA03_ED05

Administre el código fuente del taller mediante GIT, evidenciando un historial de commits con mensajes técnicos claros y el uso estructurado de ramas para organizar nuevas funcionalidades.

Trabajo Directo: 40 hrs Trabajo Autónomo: 4 hrs Soporte: AA03_ED06

Realice la conexión técnica entre los componentes de la interfaz de usuario y los servicios web construidos, garantizando la persistencia y el flujo correcto de los datos hacia la base de datos.

Trabajo Directo: 60 hrs Trabajo Autónomo: 10 hrs Soporte: AA03_ED08

Integre un componente de tecnología emergente (ej. consumo de un servicio de almacenamiento en la nube o simulación básica de IoT para el rastreo de activos) según los requerimientos del caso.

Trabajo Directo: 70 hrs Trabajo Autónomo: 8 hrs Soporte: AA03_ED08
