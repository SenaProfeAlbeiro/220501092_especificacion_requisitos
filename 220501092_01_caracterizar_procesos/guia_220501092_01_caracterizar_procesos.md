### 2. PRESENTACIÓN

En el dinámico mercado laboral de las Industrias 4.0, las organizaciones ya no solo buscan digitalizar sus procesos, sino que demandan soluciones altamente accesibles y conectadas que operen en tiempo real a través de la web y de dispositivos móviles. Tras haber superado las etapas de identificación de necesidades y diseño arquitectónico de su proyecto, este es el momento cumbre donde los requerimientos técnicos y los modelos lógicos se transforman en código fuente funcional, permitiendo que la propuesta de software que ha venido construyendo desde el primer trimestre deje de ser un plan documental para convertirse en un producto tecnológico tangible. 

La codificación profesional es el motor que impulsa la competitividad de las empresas tecnológicas a nivel mundial. Escribir código de alta calidad no es una tarea mecánica; requiere un dominio profundo de la lógica y la aplicación rigurosa de saberes técnicos como el Paradigma Orientado a Objetos, el uso de lenguajes de última generación (Java, Python, PHP, C# o Ruby), el manejo de Frameworks, la implementación de Servicios Web (REST/SOAP) y la integración de protocolos de seguridad para blindar la información contra amenazas críticas como el SQL Injection.

Esta guía es el eje central para alcanzar la competencia de **[220501096] Construcción del software de acuerdo con el diseño y metodologías de desarrollo**. Dicha competencia se integra por cinco resultados de aprendizaje:
1. [01] Planear actividades de construcción
2. [02] Construir la base de datos
3. [03] Crear componentes front-end
4. [04] Codificar el software de acuerdo con el diseño establecido
5. [05] Realizar pruebas al software

El desarrollo de esta guía se enfoca específicamente en el cuarto resultado, donde usted materializará la lógica de negocio y la integración de todos los módulos que componen su solución.

Al finalizar las actividades propuestas, usted estará en capacidad de codificar módulos de software profesionales para entornos web y móviles, creando servicios web para disponer de métodos reutilizables y utilizando herramientas de control de versiones como GIT para asegurar la trazabilidad y colaboración en su código. Lo invitamos a asumir este proceso con rigor técnico, pues de su destreza en la programación depende que el software desarrollado sea escalable, seguro y cumpla con los estándares de calidad que el sector productivo exige hoy en día.

#### 3.2 Actividades de Contextualización e Identificación de Conocimientos Necesarios para el Aprendizaje
*Momento: “Antes de Aprender”*

Estimado Aprendiz, como ha notado para codificar una solución software profesional orientada a entornos web y móviles, existe un cuerpo de conocimientos previos que debe comprender antes de iniciar la construcción física del producto; como señala la literatura técnica:

> *"La ingeniería de software comprende un proceso, un conjunto de métodos y un abanico de herramientas que permiten a los profesionales construir software de cómputo de alta calidad. Este enfoque sistemático y disciplinado es lo que diferencia a un programador profesional de un aficionado, permitiendo que la solución sea mantenible y segura"* (Pressman, 2010, p. 4).

Por tal razón, la presente guía le proporciona suficiente información en formato multimedia en la carpeta `MA - Material de Aprendizaje`. A continuación, se presentan los fundamentos teóricos de esta fase:

* **Entornos de desarrollo:** La selección de herramientas adecuadas es el primer paso hacia la calidad. Según Pressman (2010), un entorno de ingeniería de software debe proporcionar un conjunto de herramientas integradas que apoyen todas las actividades del proceso. *(MA - Material de Aprendizaje / MA01 - Entornos de desarrollo)*.
* **Programación Orientada a Objetos:** Este paradigma es el pilar de la escalabilidad moderna. Joyanes Aguilar (2008) sostiene que facilita la creación de software complejo mediante el uso de clases y objetos que encapsulan datos y comportamiento. *(MA - Material de Aprendizaje / MA02 - Programación Orientada a Objetos)*.
* **Frameworks back-end:** El uso de marcos de trabajo acelera la entrega de valor, proporcionando una infraestructura reutilizable que resuelve problemas comunes de arquitectura. *(MA - Material de Aprendizaje / MA03 - Frameworks back_end)*.
* **Seguridad de la aplicación:** Piattini et al. (2007) enfatizan que el aseguramiento de la calidad incluye la protección de los activos contra vulnerabilidades críticas como la inyección de código. *(MA - Material de Aprendizaje / MA04 - Seguridad de la aplicación)*.
* **Sistema Control de Versiones:** El estándar SWEBOK (IEEE, 2004) define la gestión de la configuración como la disciplina de identificar y controlar los cambios. Herramientas como GIT permiten el trabajo colaborativo sin pérdida de integridad. *(MA - Material de Aprendizaje / MA05 - Sistema Control de Versiones)*.
* **Servidores:** Varón (2021) explica que la infraestructura de TI para ingeniería web requiere servidores configurados para soportar arquitecturas distribuidas. *(MA - Material de Aprendizaje / MA06 - Servidores de aplicaciones)*.
* **Servicios web:** Según Sommerville (2005), la arquitectura orientada a servicios permite que los componentes se comuniquen de forma independiente mediante protocolos como REST y JSON. *(MA - Material de Aprendizaje / MA07 - Servicios web)*.
* **Cloud Computing:** Joyanes Aguilar (2012) define este modelo como una estrategia donde el software, cómputo y almacenamiento son elásticos y accesibles desde la red. *(MA - Material de Aprendizaje / MA08 - Cloud Computing)*.
* **Internet of Things:** Exige que el software de backend sea capaz de procesar eventos masivos en tiempo real procedentes de objetos conectados. *(MA - Material de Aprendizaje / MA09 - Internet of Things)*.
* **Blockchain:** Permite asegurar que cada transacción realizada sea auditable y resistente a la manipulación. *(MA - Material de Aprendizaje / MA10 - Blockchain)*.
* **Machine Learning:** Permite automatizar la toma de decisiones y personalizar la experiencia del usuario basándose en patrones históricos. *(MA - Material de Aprendizaje / MA11 - Machine Learning)*.

* **Descripción de la Actividad:** Estimado Aprendiz, con el fin de diagnosticar el conocimiento adquirido, solucione el cuestionario denominado `AA02_EC02 - Cuestionario II.docx`, ubicado en `AA - Actividades de Aprendizaje / AA02 - Contextualización`.
* **Tiempo estimado:** 72 Horas.

### 5. GLOSARIO DE TÉRMINOS

* **API (Application Programming Interface):** Conjunto de definiciones y protocolos que permite que diferentes aplicaciones de software se comuniquen entre sí, facilitando la integración de servicios web bajo estándares como REST o SOAP.
* **Blockchain:** Tecnología de registro distribuido e inmutable que asegura que cada transacción realizada en el software sea auditable y resistente a la manipulación.
* **Cloud Computing:** Estrategia de computación donde el software, la potencia de cómputo y el almacenamiento se ofrecen como servicios elásticos y accesibles desde cualquier lugar a través de internet.
* **Codificación de Software:** Proceso técnico de transformar requerimientos técnicos y modelos lógicos en código fuente funcional.
* **Control de Versiones (GIT):** Sistema diseñado para gestionar sistemáticamente los cambios realizados en el código fuente, permitiendo trazabilidad y trabajo colaborativo.
* **Framework:** Estructura o marco de trabajo predefinido que proporciona una infraestructura reutilizable de código y patrones de diseño.
* **Internet of Things (IoT):** Red de objetos físicos conectados a internet que recolectan y procesan datos en tiempo real.
* **Machine Learning:** Disciplina de la inteligencia artificial que permite que el software aprenda de patrones de datos históricos para automatizar la toma de decisiones.
* **Programación Orientada a Objetos (POO):** Paradigma de programación basado en el concepto de "objetos" y "clases" para organizar el código mediante encapsulación.
* **SQL Injection:** Vulnerabilidad crítica de seguridad que ocurre cuando un atacante inserta código SQL malicioso en las entradas de datos.
