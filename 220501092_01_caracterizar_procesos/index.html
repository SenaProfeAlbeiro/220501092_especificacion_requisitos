2. Presentación

En el contexto del mercado laboral actual impulsado por la Industria 4.0, las organizaciones requieren sistemas web y móviles altamente seguros, interoperables y capaces de procesar información en tiempo real.

Luego de definir los requerimientos y modelos de diseño arquitectónico, la codificación es el núcleo operativo donde las especificaciones lógicas se convierten en software real. Esto demanda la aplicación rigurosa de principios de la Programación Orientada a Objetos (POO), lenguajes modernos (Java, Python, PHP, JavaScript, C#), Frameworks de desarrollo, servicios web REST/SOAP e implementaciones de seguridad contra ataques como el SQL Injection.

Resultados de aprendizaje de la competencia:
  • RAP 01: Planear actividades de construcción.
  • RAP 02: Construir la base de datos.
  • RAP 03: Crear componentes front-end.
  • RAP 04: Codificar el software de acuerdo con el diseño establecido.
  • RAP 05: Realizar pruebas al software.

5. Glosario de Términos

10 Términos

API (Application Programming Interface)

Conjunto de protocolos y definiciones que permite la comunicación entre distintas aplicaciones informáticas mediante contratos estandarizados como REST o SOAP.

Blockchain

Tecnología de registro distribuido e inmutable que garantiza la trazabilidad y la integridad de transacciones sin requerir intermediarios centrales.

Cloud Computing

Suministro bajo demanda de recursos informáticos (servidores, almacenamiento y bases de datos) a través de Internet con pago por uso.

Control de Versiones (GIT)

Sistema que registra los cambios realizados sobre el código fuente a lo largo del tiempo, facilitando el trabajo colaborativo y la trazabilidad.

Framework

Estructura conceptual y tecnológica de soporte estandarizada que agiliza el desarrollo de software proporcionando componentes reutilizables.

IoT (Internet of Things)

Red de objetos físicos interconectados provistos de sensores y software para recolectar e intercambiar datos en tiempo real.

Machine Learning

Rama de la Inteligencia Artificial que permite a los sistemas aprender y mejorar automáticamente a partir de datos sin ser programados explícitamente.

POO (Programación Orientada a Objetos)

Paradigma de programación basado en el concepto de objetos que contienen datos (atributos) y código (métodos) con principios como encapsulamiento y herencia.

SQL Injection

Vulnerabilidad de seguridad que permite a atacantes interferir con las consultas que una aplicación realiza a su base de datos insertando sentencias maliciosas.

Sanitización de Datos

Proceso de limpieza y validación de las entradas de usuario para asegurar que no contengan elementos destructivos o dañinos antes de ser procesados.
